# DQ02: its complicated

Three black frames turn around a black sphere, drift apart and almost line up again. A short exercise in mindfulness: the picture and the music breathe together on a ten second cycle. Made from code in under 4kb.

[Run it](https://deadquiet42.github.io/dq02/), or open `dq02.html` in a browser and click. It plays full screen with sound.

## Build

```
npm install
npm run build
```

`dq02-source.js` is the readable source. The build minifies it with terser and packs it with roadroller into `dq02.html`.
